# Contributing

This repository is a generated snapshot of skills maintained elsewhere, so a pull request
against the Markdown here will be overwritten on the next cut. What survives:

- **Issues.** A wrong claim, a dead reference, a rule that contradicts another rule, an
  incident whose page has since been corrected. Name the file and line.
- **Proposals in an issue**, written as the rule you think should replace the current one
  and the case it would have caught. Rules in these skills each trace to a real incident;
  a proposal that cites one is far more likely to land.

If a change is accepted it is made in the canonical copy and appears here at the next tag,
with credit in the tag notes.
